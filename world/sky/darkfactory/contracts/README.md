# Contracts

Esta área guarda os contratos que definem como as partes do WordDark conversam com a Dark Factory.

## Contratos principais

### Request

Define uma solicitação de trabalho.

### Message

Define o envelope utilizado pela Rodovia.

### Response

Define o retorno da execução.

### Identity

Define a identidade da unidade que solicita ou recebe uma operação.

### Result

Define o resultado produzido por um executor.

## Regra

Contratos devem evoluir por versão e manter compatibilidade sempre que possível.

Uma cidade, estado ou empresa da Terra não deve precisar conhecer a implementação interna de um executor para utilizar um serviço autorizado.
