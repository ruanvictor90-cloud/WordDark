# LAB Core

The laboratory currently covers the foundational bricks agreed for WordDark:

- IDs and entity registry
- client/channel/project/user/service/result models
- profile + permission + context checks
- traceable operation lifecycle
- entry gates
- transport routes
- service execution registry
- external connector boundary
- error/recovery lifecycle
- notifications vs actionable inbox
- immutable version history
- end-to-end runtime composition

Nothing here replaces the operational runtime until reviewed and transplanted.
